GAUSHALA ADMIN — ONE-TIME CLOUD SETUP (NO GITHUB LOGIN IN ADMIN PANEL)

This build uses a Cloudflare Worker as a secure server-side publisher. Admins log in only with the admin email/password. GitHub credentials stay in Cloudflare secrets and are never sent to the browser. Edits from any device commit to the configured repository; GitHub Pages rebuilds the public site.

ONE-TIME SETUP REQUIRED BY THE SITE OWNER (cannot be done from this ZIP without access to your Cloudflare account):
1. Create a Cloudflare Worker named gaushala-admin-api and upload cloudflare-worker/worker.js (or deploy this folder with Wrangler).
2. Set Worker secrets/variables:
   ADMIN_EMAIL = your admin email
   ADMIN_PASSWORD = a new strong admin password
   SESSION_SECRET = a random 32+ character secret
   GITHUB_TOKEN = fine-grained GitHub token with Contents: Read and write for this repository only
   GITHUB_REPO = owner/repository-name
   GITHUB_BRANCH = main (or your actual publishing branch)
   ALLOWED_ORIGIN = exact live website origin, e.g. https://your-domain.com (no trailing slash)
3. Copy the Worker URL (https://...workers.dev) into scripts/cms-config.js as CMS_API_BASE.
4. Commit/push this ZIP contents to the GitHub Pages repository.

After this one-time configuration, the admin panel itself has no Connect with GitHub screen and no GitHub token field. Login is cloud-authenticated, sessions work independently on mobile and laptop, settings/page edits/media uploads are stored in the repository and published by the existing GitHub Pages workflow.

IMPORTANT: Do not put GITHUB_TOKEN in HTML/JS. Do not publish this Worker before setting strong secrets and ALLOWED_ORIGIN. GitHub Pages may take 1-3 minutes to deploy each save.
